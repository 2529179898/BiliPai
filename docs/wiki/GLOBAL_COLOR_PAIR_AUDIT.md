# 全局颜色配对检查

日期：2026-10-18。检查重点为自定义强调色／单独覆盖控件底色以后，前景仍沿用另一组角色所造成的对比不足。

## 确认与修正

| 入口 | 问题 | 修改边界 |
| --- | --- | --- |
| MD3 开关 | 深色滑块仍配深色勾选标记 | 已按滑块实际颜色修正开启图标；轨道、滑块、关闭及禁用态保留 |
| MD3／Miuix 复选框 | 自定义方框底色没有同时为勾选配对 | MD3 修正启用的勾选色；Miuix 仅在显式覆盖方框颜色时修正；禁用色保留 |
| MD3／Miuix 单选 | 明亮强调色在普通页面底色上难以分辨 | 按各自主题 surface 检查选中标记，原色达到 3:1 时保持；禁用色保留 |
| MD3 标签与选项 | 原始强调色或 outline 直接用于文字与选择标记 | 普通标签／选项文字使用可读强调色或次要文字角色；不改变轨道、指示器和布局 |
| 弹窗确认／取消 | 操作文字未按弹窗实际填充色配对 | 使用显式容器色或原生默认底色；MD3 默认表面同时计入 tonal elevation；仅修正操作前景 |
| 普通文字与链接 | 后备 onSurface 也可能被高级配色改成低对比颜色 | 覆盖十种常用表面角色；已有颜色可读时保留，否则选取更可读的后备色 |
| 视频关注按钮 | 主题色底上固定白色加号和文字 | 按按钮实际底色配对；关注状态、背景与布局保持 |
| 设置说明文字 | 部分标签、数字、说明直接使用原始强调色 | 改为可读强调文字角色；原始色板、图片、装饰边框不统一改色 |

## 已检查且保留

- 填充按钮已有实际底色对比修正，以及按钮槽内显式颜色修正。
- Miuix 开关的白色滑块是其原生视觉行为，不套用 MD3 的 onPrimary 规则。
- 液态滑块／开关的中性色滑块、材质高光、阴影，以及媒体遮罩上的白色图标有独立背景语义，未用全局换色覆盖。
- 壁纸角色覆盖和高级主题色中的主色／配套前景已成对处理；主题强调色作为填充色继续保留原值。

## 检查范围与限制

本次以共享设计系统入口、主题角色处理链、设置页面普通强调文字，以及视频关注按钮为重点，检查了页面白色前景与主题色底的近邻调用。没有逐帧、逐像素验证全部业务页面；透明材质、视频画面、主题过渡和调用者独立提供的背景仍需结合场景评估。

检查目标为普通文字 4.5:1，必要控制标记 3:1。新增控件前景／透明合成与不可读 onSurface 后备的回归测试源码；未编译、未运行 Gradle 测试。
