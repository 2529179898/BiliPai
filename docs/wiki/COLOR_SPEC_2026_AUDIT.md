# 外观配色与 SPEC_2026 复查

日期：2026-10-18。范围：外观设置截图中的主题颜色来源、自定义颜色、高级配色、调色板、色彩风格、色彩标准、对比度和主题色预览。

## 官方版本边界

- 接入 MaterialKolor `6.0.0-beta01` 的 Material 3 适配模块。该版本使用 Google MCU Kotlin 源码生成的引擎，包含 SPEC_2026 与 CMF。
- CMF 固定使用 SPEC_2026。TonalSpot、Neutral、Vibrant、Expressive 支持 2021／2025；请求 2026 时按官方规则使用 2025。其他现有风格使用 2021。
- 设置页列出当前风格实际支持的标准。切换 CMF 不自动改写其他风格使用的标准偏好。
- 现有默认仍为 TonalSpot + SPEC_2025；保存的风格名称继续可读取，新风格支持完整字符串往返。
- 传统扩展调色板保留自身色调规则和独立约束求解路径，不由新引擎的默认版本隐式决定。

## 深浅色与角色复查

| 选项 | 复查结论及处理 |
| --- | --- |
| 主题颜色来源 | 跟随系统保留 Android 提供的完整深／浅色方案；重新调色、自定义颜色分别使用实际种子色生成对应明暗方案。Android 12 以下保留后备方案。 |
| 自定义颜色、主题色入口 | 原先直接以原始 HEX 着色功能图标，亮色种子可能在浅色背景上辨识不足。两个入口改用语义强调色；原始 HEX 仍作为种子和色板展示。 |
| 标题、说明、右侧值 | 使用 AppContentColors 的主／次文字角色，次要内容不复用禁用色；深浅色随当前 ColorScheme 切换。 |
| 高级配色开关 | MD3 渲染器继续使用 SwitchDefaults.colors()，保留官方开启／关闭／禁用状态映射。 |
| 高级配色自定义值 | 用户覆盖背景、文字与控件色属于自定义方案；保留对比度提示与前景兜底。控件生成补齐风格／标准兼容处理，不直接强塞种子 HEX 到深浅色控件角色。 |
| 调色板 | Standard 使用官方风格引擎；Soft、CandyPop 等扩展预设使用自身规则，不宣称与 Google 官方色值逐项一致。 |
| 色彩风格、标准 | CMF 走原生 2026 的色板和角色生成；其他风格明确解析实际标准。 |
| 对比度 | Standard 将所选档位传给官方 contrastLevel；扩展调色板沿用自身策略，界面不提供无效档位。降低对比度和用户覆盖色不能视为普遍满足正文对比度要求的证明。 |
| 色板小样 | 跟随实际深浅色和当前标准；修正壁纸重新调色时风格小样误用预设后备种子的问题。 |

Material 色彩角色是一套前景／背景配对规则，不能仅凭一张深色截图判断任意种子、对比度、覆盖值和浅色界面全部合规。小字通常应达到 4.5:1；大字与必要非文字元素通常以 3:1 为参照。自定义方案、纯黑表面和应用前景兜底属于应用层调整，不能称为官方生成色值原样输出。

## 后续加强：最终配色检查与预览

- 外观设置对深浅色分别检查最终 Material 角色：各层表面文字、选中容器、固定角色和必要控件边界。透明前景先与背景合成；目标为文字 4.5:1、边界 3:1，排除禁用状态和装饰性 outlineVariant。
- 高级配色显示最终文字／选中状态示例和未达目标的配对；“修正可读性”仅更改当前模式已保存的两种文字色，保留背景及强调色，剩余问题继续显示。
- 色板、风格小样和取色器通过与实际主题共用的覆盖及液态玻璃处理函数，再经过纯黑、壁纸覆盖与原生桥接入口。选择新种子时预演与保存一致的控件色同步；编辑单独角色时保留其余字段。
- 不在普通原生主题入口新增全局配色重写；检查为诊断，文字修正由用户点击触发。透明玻璃的实际图像背景、动态过渡和未列入配对的特定组件仍需单独评估。
- 已补充预览与端点一致性、修正保留背景和强调色、透明合成、固定角色及按钮回调的测试源码；未编译或运行这些测试。
